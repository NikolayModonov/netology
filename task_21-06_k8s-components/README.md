# Домашнее задание к занятию «Компоненты Kubernetes»

Кластер Kubernetes состоит из двух основных частей: Control Plane (плоскость управления) и Worker Nodes (рабочие узлы).

## Компоненты Control Plane

- **kube-apiserver**: Центральный компонент, предоставляющий REST API. Через него проходят все запросы на управление кластером.
- **etcd**: Распределенная база данных типа ключ-значение. Хранит все конфигурации и состояние кластера.
- **kube-scheduler**: Планировщик. Отвечает за выбор подходящего узла для запуска новых подов.
- **kube-controller-manager**: Запускает фоновые процессы (контроллеры), которые следят за состоянием кластера и приводят его к желаемому виду (например, поддерживают нужное количество реплик).
- **cloud-controller-manager**: Взаимодействует с API облачного провайдера (управление балансировщиками нагрузки, дисками, узлами).

## Компоненты Worker Node

- **kubelet**: Основной агент на каждом узле. Следит за тем, чтобы контейнеры в подах были запущены и работали в соответствии с манифестами.
- **kube-proxy**: Сетевой прокси. Обеспечивает маршрутизацию трафика и балансировку нагрузки для сервисов.
- **Container Runtime**: Среда выполнения контейнеров (например, containerd или CRI-O). Отвечает за скачивание образов и непосредственный запуск контейнеров.
