# Домашнее задание к занятию «Вычислительные мощности. Балансировщики нагрузки»

## Выполнение

В Yandex Cloud с помощью Terraform создана инфраструктура:
- Бакет в Object Storage `nikolay-modonov-balancer-bucket` с загруженной картинкой `images.jpg` и публичным доступом.
- Группа виртуальных машин `lamp-group` (3 инстанса) на базе Ubuntu с установленным Apache. В `user-data` прописан скрипт, который формирует страницу `index.html`, отображающую имя хоста, публичный IP-адрес и картинку из бакета.
- Сетевой балансировщик нагрузки `lamp-balancer`, направляющий трафик на порт 80 инстансов с включенной проверкой состояния (healthcheck).
