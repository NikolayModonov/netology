# Домашнее задание к занятию «Безопасность в облачных провайдерах»

## Выполнение

В Yandex Cloud с помощью Terraform развернута защищенная инфраструктура:
1. Создан симметричный KMS-ключ `bucket-encryption-key` для шифрования данных.
2. Создан бакет Object Storage `nikolay-modonov-secure-bucket`, для которого включено серверное шифрование (SSE-KMS) с использованием созданного KMS-ключа.
3. Создана группа безопасности `web-security-group`, которая разрешает входящий трафик на порты 80 (HTTP) и 22 (SSH), а также любой исходящий трафик. Эта группа безопасности привязана к Instance Group с веб-серверами.
4. Настроен сетевой балансировщик нагрузки.
